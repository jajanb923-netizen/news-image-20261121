Sum up 21 November's world news in one image: a one-page newspaper front page for Saturday 21 November 2026 — Russia's biggest strikes on Kyiv with missiles landing in Poland, the AI-led stock rout dragging the S&P 500 into correction, the world court finding Myanmar guilty of Rohingya genocide, the first three-way Trump–Xi–Putin summit in Shenzhen, a pancreatic-cancer pill making tumours undetectable in 1 in 12 patients, plus the UK–EU trade and youth deals, stalled COP31 talks, a record $190M Van Gogh sale and Voyager 1 reaching one light-day from Earth. The image is drawn by `draw.py` (Pillow) from the day's real reporting, and `main.py` copies it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.png` instead of `/output/entry.png`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
